# Редактура против нейрояза

Этот скилл редактирует готовый русский текст так, чтобы он звучал живо, просто и человечески.

## Когда использовать

Использовать, когда пользователь просит:

- убрать нейрояз;
- сделать текст живее;
- отредактировать пост для нетехнической аудитории;
- переписать текст без канцелярита и пафоса;
- убрать признаки шаблонной генерации;
- подготовить финальную версию текста без комментариев.

## Главная задача

Сохранить смысл текста, но переписать его так, чтобы он звучал как человеческий текст, а не как текст нейросети.

Пост должен быть рассчитан на нетехническую аудиторию.

## Формат ответа

Всегда выводить только отредактированный текст.

Не добавлять:

- комментарии редактора;
- список правок;
- объяснение, что было изменено;
- дисклеймеры;
- вступление перед текстом;
- финальный вывод после текста.

## Правила редактирования

1. Убрать пафосные вводные конструкции: `в современном мире`, `в условиях быстро меняющейся реальности`, `на сегодняшний день` и похожие.
2. Убрать негативный параллелизм и псевдодраму: `не просто..., а...`, `это не..., это...`, `не X, а Y`.
3. Избавиться от рубленых предложений подряд. Текст должен течь естественно.
4. Минимизировать длинные тире. Использовать их только там, где они действительно нужны.
5. Убрать лишние кавычки.
6. Уменьшить количество слова `это`. Переписывать такие фразы естественно.
7. Убрать искусственные списки `во-первых`, `во-вторых`, если они не нужны по делу.
8. Удалить канцелярские конструкции: `данный подход`, `имеет важное значение`, `позволяет повысить эффективность`.
9. Убрать пустые экспертные фразы: `важно отметить`, `следует учитывать`, `таким образом можно сделать вывод`.
10. Избавиться от гиперобобщений: `каждый предприниматель`, `в современном бизнесе`, `в наше время`.
11. Упростить избыточные формулировки.
12. Сделать текст живым: добавить разговорную интонацию, естественные переходы и простые формулировки, как если бы автор писал сообщение знакомому.
13. Сохранить смысл текста.
14. Держать фокус на нетехнической аудитории.
15. Убирать явные английские термины и гибридные конструкции, если есть нормальная русская альтернатива. Например, `Telegram-first` заменить на `ориентированный на Telegram`, `research ops` на `исследовательские процессы`, `workflow` на `рабочий процесс`.
16. Оставлять английский только там, где это название продукта, модели, компании, API, тарифа или термин без понятной русской замены.

## Что нельзя делать

- Не добавлять новые факты.
- Не менять позицию автора.
- Не превращать текст в рекламный пост.
- Не усиливать выводы, если в исходнике их нет.
- Не сглаживать текст до одинакового ритма.
- Не оставлять технический жаргон без необходимости.
- Не оставлять англицизмы ради модного звучания.
- Не добавлять проверочные списки или редакторские заметки.

## Рабочий процесс

1. Прочитать исходный текст целиком.
2. Сохранить смысл, структуру и основные акценты.
3. Переписать предложения с нейроязом.
4. Упростить сложные и канцелярские обороты.
5. Заменить ненужные английские термины русскими словами, если смысл не меняется.
6. Сделать переходы между абзацами естественными.
7. Проверить, что текст понятен человеку без технического бэкграунда.
8. Вывести только финальный отредактированный текст.

## Мини-чеклист перед ответом

- Нет пафосного вступления.
- Нет конструкций `не просто..., а...`.
- Нет лишних длинных тире.
- Нет лишних кавычек.
- Слово `это` не повторяется слишком часто.
- Английские термины оставлены только там, где без них теряется точность.
- Нет канцелярита и пустой экспертности.
- Смысл исходника сохранен.
- Ответ содержит только отредактированный текст.

## Базовый промпт

```markdown
Отредактируй текст для русскоязычной нетехнической аудитории.

Убери нейрояз, пафос, канцелярит, негативный параллелизм, лишние кавычки, искусственные списки и ненужные английские термины.
Сделай текст живым, простым и естественным.
Сохрани смысл исходника.

Выведи только отредактированный текст без комментариев.
```
